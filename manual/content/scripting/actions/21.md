---
type: action
id: TACTION_PLAY_SPEECH
title: Play speech...
summary: Asks EVA for one spoken line, which is discarded rather than held back when she is already busy.
caveats:
  - Only one line can be waiting at a time. A line asked for while another is waiting is thrown away rather than queued behind it, so two speech actions in the same trigger leave only the first to be heard.
  - Asking for the line that is already playing, or the line that is already waiting, does nothing.
  - Nothing is spoken while the speech volume is at zero.
  - Disabling speech does not silence every line. Which ones it silences is settled by the sample the line names, not by the action that asked for it.
related:
  - type: action
    id: TACTION_DISABLE_SPEECH
  - type: action
    id: TACTION_ENABLE_SPEECH
---
