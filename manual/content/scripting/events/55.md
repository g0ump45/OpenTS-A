---
type: event
id: TEVENT_LIMPED
title: Limped
summary: Fires when a weapon carrying a limpet factor attaches its firing house's mark to the tagged object.
caveats:
  - Nothing about the attacker is examined. Any weapon whose warhead carries a limpet factor above zero attaches the mark and springs the event, whatever kind of object fires it.
  - The mark is kept one per house, so a house springs the event on a given object once. A second shot from the same house does nothing whatever — no mark, no event, and the firing object survives where the first was consumed.
  - Clearing the mark opens the event again. Healing the object, or a repair step at a service depot, clears it, after which the same house can attach a fresh mark and spring the event a second time.
  - A structure, an aircraft and a soldier can all carry a mark, so the event is not confined to vehicles even though only a vehicle is slowed by one.
  - The event runs no test of its own.
related:
  - type: system
    id: trigger-springing
  - type: key
    id: LimpetFactor
  - type: system
    id: repair
---

[`LimpetFactor`](/keys/limpetfactor/) on a warhead is the whole of the requirement, and that page owns what a mark does to the object carrying it and what clears one. The limpet drone is only the shipped case — in the stock rules the object that fires is the deployed limpet mine the drone folds into — and any other weapon given the setting springs the event in the same way.
